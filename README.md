INVENTORY tracker API + really bad looking frontend!!!!!!

a simple inventory management API with FastAPI + Brython where users can create an API key, manage stock and track low inventory items

FEATURESSSSSSSSS

Register AND store your api key locally!!!!

API key auth!!

Adding items to inventory(who wouldve thought)

View all items dynamically in a list!!

Delete items from the list!!!

CHECKS if you ACTUALLY want to delete something

unfortunately useless loading indicator as it runs too quickly

Ability to toggle between dark and light theme!!!!

Data is saved even if you refresh the page!!
